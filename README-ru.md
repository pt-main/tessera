# Tessera

> [Rust](src/lib/) (эталон) | [C](impl/c/) (быстрая) | [Lua](impl/tessera.lua) | [Go](impl/go/)

Tessera - это простой портируемый язык для хранения данных.  
Его главное преимущество - простота. Весь парсер и структура данных умещаются в 200 строк Rust.  
При этом скорость достигает 160 МБ/с на пике и около 120 МБ/с на сложных вложенных структурах.

> Подробную специфику яызка можно посмотреть в [`SPEC (en)`](docs/SPEC.md) и в [`SPEC (ru)`](docs/SPEC-ru.md)

## Зачем ещё один формат?

Потому что хочется:
- человекочитаемости,
- строгой типизации,
- минимального синтаксиса,
- скорости,
- и чтобы всё ядро было маленьким.

Tessera - это компромисс: нет массивов (кроме байтов), нет многострочной записи, зато парсинг простой и быстрый.

## Синтаксис

Всего четыре конструкции:

1. Поле: `ключ тип значение`
2. Открытие вложенной таблицы: `<имя`
3. Закрытие таблицы: `>`
4. Комментарий: `# ...` (с начала строки)

Пример:

```tessera
# Корневые поля
version i 1
title s "Example"
debug l true

<server
  host s "example.com"
  port i 8080
  <tls
    enabled l true
    cert b TUlJQ...
  >
>

<users
  <alice
    age i 30
    roles s "admin,user"
  >
>
```

Всё, что до первого `<`, попадает в корневую таблицу.  
Незакрытые блоки автоматически закрываются в конце файла.

## Типы

| Тип | Обозначение | Что это |
|-----|-------------|---------|
| `i` | `i64`       | целое число |
| `f` | `f64`       | число с плавающей точкой |
| `s` | строка      | UTF-8, можно в кавычках, можно без |
| `b` | байты       | Base64 |
| `l` | `bool`      | `true`, `false`, `1`, `0` |

## Вложенность

Таблицы вкладываются друг в друга без ограничений.  
Ключ, под которым вложенная таблица хранится в родителе, - это её имя.

## Производительность

В `src/main.rs` есть бенчмарк.  
На синтетическом файле из 100 000 вложенных блоков (около 1 млн строк) достигается:

- ~160 МБ/с на простых данных,
- ~120 МБ/с на сложных вложенных структурах.

При этом формат может быть оптимизирован почти до границы производительности железа, и эталонная реализация на rust не является эталонной по производительности.

> В разрабатываемой [C-версии](impl/c) же скорость достигает 4.7 ГБ/с (на том же железе 10ти летней давности).
> [Lua-версия](impl/tessera.lua) же имеет скорость ~6 МБ/с, а [Go-версии](impl/go) около 80 МБ/с.

## Использование

Библиотека называется `tessera`.  
Парсинг:

```rust
use tessera::{parsing::parse_into, structures::Config};

let mut cfg = Config::default();
let errors = parse_into(&mut cfg, code);
```

Генерация Tessera:

```rust
use tessera::generating::to_tessera;

let text = to_tessera(&cfg);
```

Генерация JSON:

```rust
use tessera::generating::to_json;

let json = to_json(&cfg);
```

Есть также `tessera_to_json` и `from_json`.
